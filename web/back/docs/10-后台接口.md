# 后台数据接口（`/v1/admin/*`）

> 2026-11-17。只做数据接口，页面交给前端。
> 权限：必须登录且 `users.role='admin'`（设备 token 即可，不另开后台登录）。

## 0. 怎么有第一个管理员

```powershell
.venv\Scripts\python.exe scripts\make_admin.py --list
.venv\Scripts\python.exe scripts\make_admin.py --username 三叶草
.venv\Scripts\python.exe scripts\make_admin.py --username 三叶草 --revoke
```

**故意做成手工的**：让"第一个注册的人自动是管理员"是这类系统最常见的被抢号事故。

## 1. 端点总表

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/v1/admin/overview` | 站点规模 + 密钥池健康 + 今日用量 + 近 7 天 |
| GET | `/v1/admin/users?q=&limit=&offset=` | 账号列表（搜用户名/显示名） |
| PATCH | `/v1/admin/users/{public_id}` | 改状态 / 提权 / 改显示名 |
| GET | `/v1/admin/characters` | 全部干员（**含已下架**）+ 提示词版本 |
| PATCH | `/v1/admin/characters/{slug}` | 上下架 / 改名 / 调发言权重 / 调排序 |
| GET | `/v1/admin/config` | 所有可热改的文本配置 |
| PUT | `/v1/admin/config/{key}` | 写一条配置（**写完立刻清缓存**） |
| GET | `/v1/admin/keys` | 密钥池状态（**只回状态，不回密钥**） |
| PATCH | `/v1/admin/keys/{id}` | 启停一把 key |
| GET | `/v1/admin/usage?days=7` | 按天汇总（`days` 上限 90） |
| GET | `/v1/admin/conversations/{public_id}/reasoning?limit=20` | 排障：某会话的思考过程 |

## 2. 响应形状

### overview

```json
{
  "counts": {"users": 12, "devices": 20, "conversations": 88, "messages": 4210,
             "characters": 36, "worldbook": 147},
  "keys": {"total": 47, "enabled": 25, "cooldown": 0, "disabled": 22},
  "today": {"requests": 0, "prompt_tokens": 0, "completion_tokens": 0,
            "cached_tokens": 0, "avg_ms": 0},
  "days": [{"date": "2026-11-17", "requests": 0, "prompt_tokens": 0,
            "completion_tokens": 0, "cached_tokens": 0, "avg_ms": 0}],
  "now": "2026-11-17T01:20:00+00:00"
}
```

`days` 只包含**有请求的日期**，前端自己补零。

### users

```json
{"total": 12, "limit": 50, "offset": 0,
 "items": [{"id": "u_public_id", "username": "三叶草", "display_name": "三叶草",
            "status": "active", "role": "admin", "devices": 2,
            "created_at": "…", "last_seen_at": "…"}]}
```

`PATCH` 只传要改的字段：`{"status": "disabled"}` / `{"role": "admin"}` / `{"display_name": "…"}`。
**不能给自己降权**（400 `cannot_demote_self`），免得把自己锁在门外。

### keys

```json
{"items": [{"id": 1, "label": "主号", "enabled": true, "cooling": false,
            "cooldown_until": null, "fail_count": 0, "rpm": 10,
            "base_url": "https://api.agnes-ai.cn", "model": "agnes-2.5-flash",
            "last_used_at": null}]}
```

`key_enc` 连密文都不返回 —— 前端拿它没用，多传一次就多一个泄露面。

## 3. 三条约定

1. **所有写操作只写一列**。批量编辑容易一次做错全站，需要批量就前端循环调。
2. **配置写完立刻生效**：`PUT /admin/config/{key}` 会调 `content_repo.clear_cache()`，
   不然安全协议要等 60 秒缓存过期（这是线上最容易误判成"没保存"的地方）。
3. **没有分页的端点不分页**（characters / keys / config 都是几十条的量级）。
