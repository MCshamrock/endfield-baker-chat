## 1. 先对比：v322kit 的 AppHeader vs 3.1 线的 AppHeader

比的是 `frontend-src/v322kit/src/components/layout/AppHeader.vue` 与改造前本工程同名文件。

| 维度 | 3.1 线（改前） | 3.2.2（改后） |
|---|---|---|
| 布局 | 一条透明横栏：左品牌 + 中间页签，`justify-content:center` | 同一条横栏、同样居中，但控制带里多一格 |
| 页签 | 只有「单聊 / 群聊」两格，`ChatModeTabs` 无插槽 | 「单聊 / 群聊 / **设置**」三格同级；`ChatModeTabs` 新增 `#trailing` 插槽，设置键作为**尾格**插在同一条 `.pn-tabs` 背板里 |
| 设置键位置 | 左侧列表操作带右组（与「公告 / 用量」挤在一起） | 顶栏控制带尾格；**不再**出现在列表操作带 |
| 设置键语义 | —— | 不是模式：无选中黄块、不参与 `select()`，`aria-label="设置"`；图标与设置面板第一个页签共用 `SETTINGS_ENTRY_ICON`（点了哪个图标，进去第一格就是它） |
| 分隔线 | 无（`.pn-tab::after` 默认隐藏与否看层级） | 顶栏显式 `:deep(.pn-tab)::after { display:none }` —— 三格靠图标与留白读清，不加竖线 |
| 桌面尺寸 | 1920 画布，顶栏 80px，页签 86×72 | 一致（未改桌面画布方案） |
| 移动端断点/定位 | `position:fixed; right:0`（缺 `left:0`）+ `width:auto` → 盒子缩到内容宽、贴右边缘，绝对定位的品牌标题会和页签叠 | `position:fixed; left:0; right:0`，控制带整条**居中**；`height:calc(50px + var(--safe-top))` + `padding-top: var(--safe-top)` |
| 移动端标题 | 固定 13px，不省略 | `max-width: calc(50vw - 100px)`（= 带子半宽 80 + 左边距 12 + 呼吸缝 8），12px + `text-overflow:ellipsis`，**绝不钻到页签下面** |
| 移动端页签 | 56×50、padding 0 14px | 48×50、padding 0 8px（三格等宽，48 ≥ 44 触控下限），图标 20×20 |
| 背景/装饰 | 顶栏透明，斜纹只来自页签背板 | 同（刻意不在顶栏再画一层，否则两层斜纹叠） |

> 结论：3.2.2 的差别就三件事 —— **设置键进控制带当第三格**、**手机端改回整条居中 + 标题让位**、
> **三格等宽**。桌面设计画布（1920 等比缩放）本工程已有，原样保留。

## 3. 主题与暗色

本工程只有**一套深色面板**（`styles/panel.scss` 的 `$pn-yellow` 等），没有 `data-theme` 双主题。
所以"不要写死颜色"的落地方式是：

- 全部颜色取自 `styles/_variables.scss` 的语义 token（新加的那一组 + 既有 `$color-text-primary`）；
- 唯一的"白"是二维码/头图的**素材白底板**（`$color-paper`）——不是主题色，是**为了看得清**：
  - 头图是透明底 Q 版立绘，垫白底板才在深色面板上不糊（截图 02）；
  - 二维码是深色卡片图，**不加滤镜/透明度**（加了会降对比度扫不出来）；
- 免责声明弹窗是白底壳（`VersionDialogShell` 的 `.fx__body`），所以那一层用 `$color-paper-ink`，
  不能用主题白字（否则白底白字）。
