## 1. 这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 一份可以直接 `vite build` 出网页包的 Vue 3 前端 | 不是从零重写的新界面 |
| **服务器上最新的网页源码**（v2 线）的 web 部分 | 不含 Windows（Electron）/ 安卓（Capacitor）/ HBuilderX 外层包装 |
| 中间层按新后端 `/v1` 契约重写（单聊 / 群聊 / 附件 / 推荐 / 账号） | 没有改组件布局、样式、素材、原有交互流程 |
| 新增：设置里的「账号」页、群聊「加权模式」+ 建群后的「发言权重」弹窗 | 没有动主界面排版 |

一句话：**界面是最新的网页版，管道接的是新后端。**

## 3. 两分钟跑起来

前提：后端在 `127.0.0.1:5660`（起法见 [`04-验收与自测.md`](04-验收与自测.md) §1）。

```powershell
cd F:\dshworkspace\BakerAI\BakerAI_new\web\front
npm ci
npm run dev        # http://localhost:5173
```

开发服务器把 `/v1`、`/group`、`/readyz` 代理到 5660；后端不在本机时
`$env:BAKER_DEV_BACKEND='http://<ip>:5660'`。

生产构建：`npm run build` → `dist/`（建议同源部署，反代 `/v1`、`/group` 到后端）。

地址解析顺序：`localStorage['baker_backend_url']` → `VITE_BAKER_BACKEND` →
`file://` 回退 `127.0.0.1:5660` → 同源。

## 4. 自测

```powershell
node scripts/contract-smoke.mjs   # 27 项：设备/元信息/角色/会话/导入/附件/账号
node scripts/claim-smoke.mjs      # 39 项：取件码上传/验码/领取/注册带码（自带假后端，无需真后端）
node scripts/adapter-e2e.mjs      # 16 项：单聊导入、幂等键、图片、绑定复用
node scripts/group-e2e.mjs        # 24 项：建群/导入/round 全员/assign/权重
```

`claim-smoke.mjs` 自带一个 Node 假后端（随机端口），不需要任何服务在跑；
它把 `src/utils/cloudData.ts` / `auth.ts` 用 esbuild 现打成模块后**直接调用**，
测的是界面里真正跑的那段请求代码。真后端就绪后可补跑：

```powershell
node scripts/claim-smoke.mjs --live                        # 打 127.0.0.1:5660
$env:BAKER_BACKEND='http://<ip>:<port>'; node scripts/claim-smoke.mjs
```

`--live` 只跑"一定会发生"的路径；413 / 507 / 429 / 410 需要制造事故才能触发，
在假后端模式里已覆盖（详见脚本头部注释）。

全部**不消耗上游模型额度**：生成回复的那一次请求被拦截成假回复，或统一用
`generate=false`。界面层另有手工验收步骤，见 04 §4。
